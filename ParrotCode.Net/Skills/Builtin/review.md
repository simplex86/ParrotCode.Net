# Code Review SOP

执行代码审查时遵循以下步骤：

1. 调用 `run_command` 执行 `git diff` 或 `git status` 确认审查范围
2. 用 `read_file` 逐个阅读变更的文件
3. 从以下维度审查：
   - **正确性**：逻辑是否正确，边界条件是否处理
   - **可读性**：命名、注释、代码结构
   - **安全性**：输入校验、权限、敏感信息
   - **性能**：明显的性能问题
   - **一致性**：是否符合既有代码风格
4. 生成结构化的审查报告：
   ```
   ## 审查结论
   - 总体评价：[通过/需修改/需重做]

   ## 问题列表
   - [严重] 文件:行号 - 问题描述
   - [建议] 文件:行号 - 改进建议

   ## 亮点
   - 值得肯定的设计或实现
   ```
5. 不要直接修改代码，仅提供审查意见
